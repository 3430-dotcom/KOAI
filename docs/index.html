KOAI · IOAI 2026 출제 기준

국가대표 선발을 향한 학습 기록

한국인공지능올림피아드(KOAI)는 국제인공지능올림피아드(IOAI)에 파견할 대한민국 대표를 선발하는 국내 공식 대회입니다. 이 페이지는 IOAI 2026 출제 기준 1~4과목을 기준으로, 무엇을 이미 익혔고 무엇이 남았는지를 있는 그대로 기록합니다.

5/60

전체 출제 항목 중 완료 8.3%

  • 1과목 기초·고전 ML
  • 2과목 신경망·딥러닝
  • 3과목 컴퓨터 비전
  • 4과목 NLP·오디오

과목별 진행 상황

각 항목은 이론과 실전으로 나뉩니다. 이론은 원리를, 실전은 코드로 구현하고 데이터에 적용하는 능력을 뜻합니다.

01 기초 역량 및 고전 머신러닝 20%

01-1 프로그래밍 기초 5/7

  • Python 기초 (반복문, 함수 등)실전
  • 데이터 처리용 NumPy, Pandas실전
  • 시각화용 Matplotlib, Seaborn실전
  • 머신러닝용 Scikit-learn실전
  • PyTorch 기초 (tensorflow만)실전
  • 텐서(다차원 배열) 조작실전
  • CPU/GPU에서의 모델 학습실전

01-2 지도학습 0/7

  • 선형회귀이론실전
  • 로지스틱 회귀이론실전
  • L1, L2 정규화이론실전
  • K-최근접 이웃 (K-NN)이론실전
  • 의사결정 트리이론실전
  • 앙상블 모델 (Gradient Boosting, Bagging, Random Forest)실전
  • 서포트 벡터 머신 (SVM)이론실전

01-3 비지도학습 0/4

  • K-평균 군집화이론실전
  • 주성분 분석 (PCA)이론실전
  • t-SNE, UMAP실전
  • DBSCAN, 계층적 군집화, 스펙트럼 군집화실전

01-4 데이터 사이언스 기초 0/7

  • 모델 평가 지표 (정확도, 정밀도, 재현율, F1 등)이론실전
  • 과소적합, 과대적합이론
  • 하이퍼파라미터 튜닝실전
  • 교차검증실전
  • 혼동행렬, ROC 곡선이론실전
  • 피처 엔지니어링실전
  • 데이터 전처리실전
02 신경망 및 딥러닝 0%

02-1 신경망 0/5

  • 퍼셉트론 기초이론실전
  • 경사하강법이론실전
  • 역전파이론실전
  • 활성화 함수 (ReLU, Sigmoid, Tanh)이론실전
  • 손실 함수 (MSE, MAE, Cross Entropy 등)이론실전

02-2 딥러닝 0/13

  • 다층 퍼셉트론 (MLP)이론실전
  • 데이터 임베딩 (텍스트, 이미지, 오디오)이론실전
  • 풀링 기법 (Max, Average)이론실전
  • 어텐션 메커니즘이론실전
  • 트랜스포머 (이론은 텍스트·이미지에 한함)이론실전
  • 오토인코더실전
  • SGD, 미니배치 경사하강법이론실전
  • 모멘텀 기반 기법 (Adam, AdamW)실전
  • 수렴성과 학습률실전
  • 정규화 (Dropout, Early Stopping, Weight Decay)실전
  • 가중치 초기화실전
  • 배치 정규화실전
  • 모델 파인튜닝 (full 및 PEFT)실전
03 컴퓨터 비전 0%

03-1 컴퓨터 비전 기초 0/10

  • 합성곱 레이어이론실전
  • 이미지 분류실전
  • 객체 탐지 (YOLO, SSD, DETR)실전
  • 이미지 분할 (U-Net)실전
  • 사전학습 비전 인코더 (ResNet 등)실전
  • 이미지 증강실전
  • GAN을 이용한 이미지 생성실전
  • 비전 자기지도학습실전
  • 비전-텍스트 인코더 (CLIP 등)실전
  • 디퓨전 모델실전
04 자연어 처리 및 오디오 0%

04-1 자연어 처리 0/5

  • 텍스트 분류실전
  • 사전학습 텍스트 인코더 (BERT 등)이론실전
  • 언어 모델링이론실전
  • 인코더-디코더 모델 (기계번역, 비전-언어 모델링 등)실전
  • 사전학습 언어 모델 (오픈소스 및 API 기반)실전

04-2 오디오 처리 0/2
