# KOAI

인공지능 학습 기록과 프로젝트 저장소.
학습 파트의 분류는 [KOAI/IOAI 출제 기준](https://kitpa.org/koai/syllabus)을 따릅니다.

## 저장소 구조

```
├── 01-foundations-classical-ml/   # 1과목: 기초 역량 및 고전 머신러닝
├── 02-neural-networks-dl/         # 2과목: 신경망 및 딥러닝
├── 03-computer-vision/            # 3과목: 컴퓨터 비전
├── 04-nlp-audio/                  # 4과목: 자연어 처리 및 오디오
└── projects/                      # 프로젝트별 기록
```

## 문서 규칙

| 파일 | 대상 |
|---|---|
| `notes.md` | 개념 정리 — 출제 기준에서 **이론 O**인 항목 |
| `*.ipynb` | 구현 노트북 — 출제 기준에서 **실전 O**인 항목 |

- 실험 노트북은 결과를 냈으면 반드시 커밋한다.
- 예상과 다른 결과가 나온 경우, 무엇을 예상했고 왜 틀렸는지를 `notes.md`에 남긴다.
- 커밋 메시지는 무엇을 했는지 알아볼 수 있게 쓴다.
